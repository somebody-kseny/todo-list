### О репозитории

"Yet another" todo-лист на React.

Возможности:

- Cписок сохраняется в localStorage
- Пункт списка можно редактировать, помечать выполненным, удалять
- Можно вернуть удаленные пункты списка (до 20 штук)
- Светлая и тёмная темы
